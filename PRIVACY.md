# Privacy Policy — TTS Anything

**Last updated:** April 2, 2026

TTS Anything is a macOS menu bar app that converts text to speech.

## What data is collected

None. TTS Anything does not collect, store, or transmit any personal data, analytics, or usage information.

## Third-party services

If you provide an OpenAI API key, text you submit for speech synthesis is sent directly to OpenAI's API. This is initiated only when you explicitly request it. TTS Anything does not store or log this text beyond the current session.

OpenAI's privacy policy applies to data processed by their API: https://openai.com/privacy

If no API key is configured, all processing happens locally on your Mac using the built-in macOS speech engine. No data leaves your device.

## API key storage

Your OpenAI API key is stored locally on your device in UserDefaults. It is never transmitted anywhere other than directly to OpenAI's API.

## Contact

For questions about this policy, open an issue at https://github.com/pauabella/ttsanything
