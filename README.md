# TTS Anything

A tiny macOS menu bar app that reads text aloud. Paste text or hit a shortcut to hear your clipboard. Fast, simple, stays out of your way.

## How it works

1. Click the menu bar icon or press the global shortcut
2. Paste text and hit Enter, or let it read your clipboard directly
3. Control playback with the built-in player

## Features

- Global keyboard shortcut to read clipboard instantly
- High-quality voices via OpenAI TTS (API key required)
- Built-in fallback to macOS system voice — works with no setup
- Playback controls with scrubber, skip, and adjustable speed
- Replay last audio without re-generating
